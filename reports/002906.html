计算口径

  1. 净值频率按相邻日期间隔中位数自动识别为日频，年化因子取 252；收益按相邻净值点计算，缺失日期不插值。
  2. 年化收益 = (1 + 区间累计收益)^(365 / 区间自然日数) − 1；年化波动率 = 每期收益样本标准差 × √年化因子。
  3. 夏普比率 = (年化收益 − 无风险利率 1.5%) / 年化波动率；卡玛比率 = 年化收益 / 最大回撤。
  4. 最大回撤 = 净值相对历史最高点的最大跌幅；修复天数 = 谷底日至首次回到前高的自然日数。
  5. 月度收益取每月最后一个净值点计算；首月以首个净值点为起点，可能为不完整月份。
  6. 基准按产品净值日期对齐，取当天或之前最近一个交易日的收盘价（不使用未来数据）；基准为价格指数，不含分红。
  7. 超额采用几何口径：超额净值 = 产品归一净值 / 基准归一点位；年化超额为超额净值的年化收益；跟踪误差 = 超额净值每期收益标准差 × √年化因子；信息比率 = 年化超额 / 跟踪误差。
  8. 月度超额 = (1 + 产品月收益) / (1 + 基准月收益) − 1；滚动 N 个月超额 = 当期超额净值 / N 个月前（当天或之前最近）超额净值 − 1。
  9. 全收益对照：用中证500全收益（成分股分红再投资）按同样口径重算年化超额与信息比率；指增产品能拿到分红，全收益口径更公允。
